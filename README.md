# Node.js Load Balancer

A load balancer built from scratch using Node.js and Express to understand distributed systems and system design concepts.

## Features

- Reverse Proxy
- Round Robin Load Balancing
- Multiple Backend Servers
- Error Handling

## Tech Stack

- Node.js
- Express
- Axios
